M2 Migration – Archive Inventory

The M2 document archive (drive Z: “M2 Archiv”, e.g. Z:\ARVIS-PH) keeps one folder per mandate: AP-00031-ENT, AP-00035-ACC, … When the M2 database itself cannot be shared, the folder structure still tells which client has which documents. The archive inventory reads only that structure: path, size and date of every file. No file is opened or copied.

1. Make the inventory (Windows)

Copy tools\m2_archive_inventory.ps1 to the Windows machine and run:

powershell -ExecutionPolicy Bypass -File m2_archive_inventory.ps1 -Root 'Z:\ARVIS-PH'

It writes Documents\M2 Archive inventory.csv (or the path given with -Out) and prints the number of files and folders. -Root 'Z:\' lists every holder folder of the drive in one file. Thumbs.db, desktop.ini and Office lock files are left out.

Without the script, the same in one line:

Get-ChildItem 'Z:\ARVIS-PH' -Recurse -File | Select-Object @{n='Path';e={$_.FullName.Substring(3)}}, Length, @{n='Modified';e={$_.LastWriteTime.ToString('yyyy-MM-dd HH:mm')}} | Export-Csv "$env:USERPROFILE\Documents\M2 Archive inventory.csv" -NoTypeInformation -Encoding UTF8

2. Use it

Put the CSV in the folder with the M2 exports (or alone in a folder, for an archive-only run) and run the migration. The file is recognised as Archive inventory (file list) by its headers Path, Length, Modified (also FullName, LastWriteTime).

Path in the inventoryRead as
ARVIS-PH\AP-00031-ENT\KYC\Passport.pdfMandate AP-00031-ENT = AP-31-ENT (zero padding ignored), holder archive ARVIS-PH, sub-folder KYC
ARVIS-PH\AP-00054-ACC\scan.pdfMandate AP-54-ACC, no sub-folder
ARVIS-PH\Thumbs.dbNot under a mandate folder: not indexed (one warning per folder)

3. Rules

RuleLevelMeaning
ARCHIVE_FOLDERdecisionFolder linked to a client of the exports; its files are indexed
ARCHIVE_FOLDER_UNKNOWNwarning (info in an archive-only run)Folder named like a mandate, but not a mandate of the exports (closed, or exported under another number); indexed under the folder name
ARCHIVE_NOT_MANDATEwarningFiles not under a mandate folder
ARCHIVE_NO_FOLDERwarningOpen mandates of the exports with no archive folder

The files appear in Finance › Documents and in the Documents sheet of the review workbook with “On disk” = archive: …. AI assistant › Classify documents then types each file and lists the clients missing KYC documents (all on this machine).

The inventory holds client names in file names: keep it on internal shares, like the exports.
